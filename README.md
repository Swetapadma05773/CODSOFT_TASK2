# Python Calculator

## About the Project
This is a simple calculator developed using Python as part of my CodSoft Python Programming Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Invalid-input handling
- Multiple calculations
- Exit option

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python calculator.py
